# NLP - Natural Language Processing

This repository contains my hands-on implementations of core NLP concepts using Python.

## Notebooks Included
- Text_preprocessing_1 & 2: Tokenization, Stemming, Lemmatization, Stopword Removal
- word2vec.ipynb: Word Embeddings with Gensim & Skip-gram
- ENCODER_&_DECODER.ipynb: Seq2Seq Architecture

## Tech Stack
Python, NLTK, Gensim, TensorFlow/Keras, Google Colab
